# 모바일 노코드 DB 랜딩페이지 제작툴 MVP

1차 개발본입니다.

## 포함 범위

- 모바일 전용 랜딩 렌더러
- PC 전용 편집기
- 모바일 접속 시 편집 불가 안내
- 블록 추가/삭제/복제/순서 변경/숨김
- 히어로, 이미지, 글, CTA, 링크 위젯, 타이머, 상담폼, 방문예약, 푸터
- 하단 고정 CTA
- 무료 버전 브랜드 노출 구조
- LocalStorage 저장 기반 프로토타입

## 실행 방법

```bash
npm install
npm run dev
```

## 현재 상태

이 버전은 랜딩 제작 UX와 모바일 결과물 확인용 프론트 MVP입니다.
Supabase, 실제 회원가입, 실제 DB 저장, 이메일 알림, 구글시트/Make 연동은 아직 붙이지 않았습니다.
다음 패치에서는 랜딩 블록 디자인 완성도와 편집 UX를 더 다듬는 흐름이 맞습니다.
