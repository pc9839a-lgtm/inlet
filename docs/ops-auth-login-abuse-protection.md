# 로그인 무차별 대입 방지

## 적용 범위

- 동일 요청자와 동일 계정 조합은 15분 동안 실패 5회부터 제한한다.
- 동일 계정은 15분 8회, 24시간 30회부터 제한한다.
- 동일 요청자는 10분 30회, 24시간 150회부터 제한한다.
- 차단된 요청은 `auth.login_rate_limited`로 기록하며 실패 횟수를 계속 늘리지 않는다.
- 제한 응답은 계정 존재 여부와 관계없이 `AUTH_LOGIN_RATE_LIMITED`로 통일한다.

## 개인정보 보호

- 이메일은 감사 로그용 HMAC 식별자로만 조회한다.
- 요청 IP도 감사 Secret으로 HMAC 처리하며 원본 IP를 응답이나 제한 조회에 사용하지 않는다.
- 존재하지 않는 계정과 잘못된 비밀번호는 같은 `AUTH_LOGIN_INVALID` 응답을 사용한다.
- 비밀번호 비교는 존재 여부와 관계없이 후보 해시와 더미 해시를 모두 계산하고 상수시간 비교 루프를 수행한다.
- 비밀번호 로그인 응답은 성공·실패 모두 최소 처리 시간을 적용해 계정 존재 여부의 시간차를 줄인다.

## 저장 방식

기존 `audit_logs`의 `auth.login_failed` 기록을 읽어 제한을 계산한다. 별도 D1 migration은 필요하지 않다. 감사 테이블 조회가 일시적으로 실패하면 로그인 자체를 중단하지 않고 경고 코드만 기록한다.

## 비변경 범위

- 공개 메인과 템플릿
- 클래식 3,500원 / 프로 5,500원
- 일반계정 1페이지 / 플랫폼 마스터 무제한
- Google 로그인 흐름
- CallTag
- SES·DNS·D1 schema
