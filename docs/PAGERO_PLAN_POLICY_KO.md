# 페이지로 요금제 정책

최종 확정일: 2026-08-01

대상 저장소: `pc9839a-lgtm/inlet`

## 확정 요금제

페이지로의 유료 요금제는 아래 두 개만 운영한다.

| 플랜 ID | 표시명 | 월 요금 |
| --- | --- | ---: |
| `classic` | 클래식 | 3,500원 |
| `pro` | 프로 | 5,500원 |

## 절대 규칙

- 유료 요금제는 클래식과 프로 두 개로 끝낸다.
- 3,300원, 6,600원, 9,900원으로 구성된 기존 3단계 요금제 방향은 폐기한다.
- 세 번째 유료 플랜을 추가하지 않는다.
- 화면, 서버 권한, 결제 상품, 웹훅, 관리자 화면은 동일한 `classic` 및 `pro` 식별자를 사용한다.
- 무료 체험이나 일시적 프로모션은 별도 혜택이며 새로운 요금제로 취급하지 않는다.
- 각 플랜의 랜딩 개수, 월 접수량, 통계 보관기간, 매니저 수, 커스텀 도메인, 외부 연동 등 세부 권한은 사용자가 별도로 확정하기 전까지 임의로 정하지 않는다.
- 결제 구현 전 세부 권한을 확정하고 서버에서 강제한다. 화면 버튼만 숨기는 방식으로 제한하지 않는다.

## 현재 적용 범위

이 문서는 요금제 명칭과 가격 정책을 확정한다. 결제사 연동, 정기결제, 빌링키, 웹훅 및 플랜별 세부 권한 구현은 별도 패치로 진행한다.
