# 페이지로 메인 홈 재작업 지시서

## 목표

메인 홈은 한 문장으로 이해돼야 한다.

```text
모바일 페이지를 빠르게 만들고, 신청까지 받는 서비스
```

사용자는 아래만 바로 알아야 한다.

- 모바일 페이지를 만든다.
- 상담, 예약, 문의, 이벤트 신청을 받을 수 있다.
- 만든 페이지를 바로 공유한다.
- 접수함에서 신청을 확인한다.

## 카피 원칙

- 짧게 쓴다.
- 길게 풀어 설명하지 않는다.
- 카드 문구는 한 줄 중심으로 쓴다.
- 개발자 용어를 쓰지 않는다.
- 비용 표현은 `0원`으로만 쓴다.
- `가입비`, `심사비`, `입점비` 같은 말은 쓰지 않는다.
- `Inlet`, `인렛` 표기는 쓰지 않는다.
- 전체는 중앙 정렬을 기본으로 한다.

## 히어로

배지:

```text
모바일 랜딩페이지 제작 도구
```

메인 카피:

```text
모바일 페이지를
빠르게 만드세요
```

서브 카피:

```text
상담, 예약, 문의, 이벤트 신청까지
필요한 페이지를 바로 만들 수 있습니다.
```

활용 칩:

```text
상담 신청
방문 예약
견적 문의
이벤트 접수
```

버튼:

```text
무료로 시작하기
로그인
```

구성:

- 중앙 정렬.
- 메인 카피가 가장 크게 보여야 한다.
- 설명은 두 줄 이내.
- 히어로에 긴 문단을 넣지 않는다.

## 섹션 1. 만들 수 있는 페이지

대제목:

```text
필요한 페이지를
바로 만드세요
```

카드:

```text
상담 신청
이름, 연락처, 상담 내용
```

```text
방문 예약
날짜, 시간, 방문 정보
```

```text
견적 문의
조건, 예산, 요청사항
```

```text
이벤트 접수
쿠폰, 체험단, 설명회
```

구성:

- 카드 4개.
- 카드 제목은 5자 내외로 짧게.
- 설명은 한 줄만.

## 섹션 2. 페이지로 고유 흐름 보드

대제목:

```text
주소부터 접수까지
한 흐름으로 이어집니다
```

보드 1:

```text
URL 설정
pagero.kr/my-page
광고, 문자, 카카오, QR에 바로 연결할 주소입니다.
```

보드 2:

```text
무료 상담 신청
이미지
문의 버튼
신청 폼
```

보드 3:

```text
접수함
오늘 접수 12건
이름, 연락처, 문의 내용, 유입 정보를 확인합니다.
```

단계:

```text
01 주소를 먼저 정합니다
공유할 URL을 확정하고 페이지를 시작합니다.
```

```text
02 필요한 블록을 배치합니다
이미지, 문의, 예약, FAQ를 목적에 맞게 넣습니다.
```

```text
03 신청을 접수함에서 봅니다
연락처, 문의 내용, 유입 정보를 한곳에서 확인합니다.
```

구성:

- 특정 레퍼런스의 `5분`, `0원`, `그래프` 3카드 구조를 그대로 쓰지 않는다.
- 페이지로의 핵심 차별점인 URL, 모바일 페이지, 접수함 흐름을 보여준다.
- 한 화면에서 제품 사용 흐름이 이해돼야 한다.
- 모바일에서는 1열.

## 섹션 3. 만드는 흐름

대제목:

```text
필요한 블록만
넣으면 됩니다
```

단계:

```text
01 URL 정하기
주소 먼저 정하기
```

```text
02 시작 방식 선택
AI, 템플릿, 직접
```

```text
03 위젯 추가
필요한 기능만 추가
```

```text
04 공유
링크로 바로 공유
```

구성:

- 4단계.
- 각 설명은 한 줄.
- `20여가지` 같은 숫자는 화면이 복잡해지면 빼도 된다.

## 섹션 4. 접수 관리

대제목:

```text
CSV다운로드부터
실시간 구글시트 연동까지!
```

카드:

```text
접수 정보
이름, 연락처, 문의 내용
```

```text
유입 정보
URL, UTM, referrer
```

```text
중복 차단
IP, 쿠키, 연락처
```

```text
CSV 다운로드
월별 데이터 저장
```

주의:

- 사용자가 준 카피를 임의로 낮추거나 바꾸지 않는다.
- 접수 관리 섹션의 핵심은 CSV 다운로드와 실시간 구글시트 연동이다.

## 섹션 5. 활용 예시

대제목:

```text
이런 곳에
바로 쓸 수 있어요
```

카드:

```text
광고 상담
혜택 안내 -> 상담 신청
```

```text
병원·뷰티 예약
시술 안내 -> 예약 접수
```

```text
견적 문의
조건 입력 -> 상담 준비
```

```text
강의·이벤트 모집
일정 안내 -> 신청 접수
```

구성:

- 흐름은 2단계만 보여준다.
- 긴 화살표 문장은 쓰지 않는다.

## 섹션 6. 활용방안

대제목:

```text
목적에 맞게
바꿔 쓰세요
```

항목:

```text
랜딩페이지
온라인 명함
청첩장
프로필 링크
이벤트 페이지
상담폼
```

구성:

- 작은 카드 또는 썸네일.
- 이름만 보여줘도 된다.
- 설명 문구는 최소화한다.

## 구현 체크리스트

- 전체 중앙 정렬.
- 히어로 문구는 짧게.
- 히어로 첫 화면에서 서비스 정체성이 보여야 한다.
- 페이지로 고유 흐름 보드를 추가한다.
- `0원` 표현만 사용한다.
- 긴 설명문을 만들지 않는다.
- 카드 설명은 한 줄로 제한한다.
- 모바일에서 가로 스크롤이 없어야 한다.
- `Inlet`, `인렛` 표기는 쓰지 않는다.
