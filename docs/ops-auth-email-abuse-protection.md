# 인증 메일 악용 방지

## 적용 범위

- 기존 이메일·목적 기준 60초 재요청 제한과 일 20회 제한을 유지한다.
- Cloudflare `CF-Connecting-IP`를 서버 Secret으로 HMAC 처리한 24자리 키를 사용한다.
- 원본 IP는 인증 테이블, 응답, 로그에 저장하지 않는다.
- 동일 요청자·동일 목적은 10분 8회, 24시간 30회로 제한한다.
- 동일 요청자 전체 목적 합계는 10분 20회, 24시간 80회로 제한한다.
- 제한 응답은 공통 `EMAIL_VERIFICATION_RATE_LIMITED` 코드와 재시도 시간만 반환한다.

## 저장 방식

별도 D1 migration 없이 인증 레코드의 기존 기본키 앞부분에 HMAC 요청자 키를 포함한다. SQLite 기본키 범위 조회로 요청자별 횟수를 계산하며 이메일과 원본 IP는 기본키에 포함하지 않는다.

## 안전 기준

- 이메일 주소를 바꿔가며 요청해도 요청자 제한을 우회할 수 없어야 한다.
- 회원가입·비밀번호 재설정·이메일 변경 목적을 바꿔가며 요청해도 전체 제한이 적용되어야 한다.
- 메일 발송 실패 시 기존 정리 로직이 인증 레코드를 삭제한다.
- 공개 메인, 템플릿, 가격, 1페이지 정책, CallTag는 변경하지 않는다.
