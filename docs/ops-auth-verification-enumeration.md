# 인증 계정 존재 여부 보호

## 회원가입·이메일 변경

인증메일 요청 단계에서는 해당 이메일이 이미 등록됐는지 반환하지 않는다. 인증코드를 실제 이메일 소유자가 확인한 뒤 최종 회원가입 또는 이메일 변경 단계에서만 중복 여부를 판정한다.

## 비밀번호 재설정

- 등록된 계정이면 인증메일을 발송한다.
- 등록되지 않은 이메일이면 인증 레코드와 요청 제한은 동일하게 적용하지만 외부 메일은 발송하지 않는다.
- 두 경우 모두 동일한 200 응답, `pending` 상태, `api/accepted` 전달 상태를 반환한다.
- 성공 응답은 최소 650ms 이후 반환해 단순 응답 시간 비교를 어렵게 한다.
- 실제 메일 공급자 오류도 비밀번호 재설정 요청에서는 동일한 접수 응답으로 처리한다.
- 분당·일일·요청자별 제한 오류는 기존 429 응답을 유지한다.

## 비변경

공개 메인, 템플릿 3종, 가격, 일반계정 1페이지 정책, CallTag, D1 schema는 변경하지 않는다.
