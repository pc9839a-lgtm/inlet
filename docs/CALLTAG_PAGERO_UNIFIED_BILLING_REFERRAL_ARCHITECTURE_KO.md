# 콜태그·페이지로 공통 결제·이용권·추천인 아키텍처

- 작성일: 2026-08-04
- 상태: 제품 정책 정본 초안
- 대상 저장소: `pc9839a-lgtm/inlet`
- 연관 앱 저장소: `pc9839a-lgtm/calltag`

## 1. 핵심 결정

콜태그와 페이지로는 서로 연동되지만 종속 관계가 아닌 별도 서비스다.

- 콜태그: 전화·문자 기반 고객관리 Android 앱
- 페이지로: 랜딩페이지 제작·문의 수집 웹서비스
- 연동 기능: 페이지로 문의를 콜태그 고객으로 자동 등록

따라서 결제 화면은 서비스별로 제공하되, 회원·이용권·무료기간·추천인·정산 판정은 하나의 서버에서 통합 관리한다.

## 2. 판매 상품과 가격

모든 가격은 부가세 별도 기준이다.

| 상품 코드 | 상품명 | 월 이용료 | 기본 판매 채널 |
|---|---:|---:|---|
| `call_monthly` | 전화관리 | 1,900원 | 콜태그 Android |
| `message_monthly` | 문자자동화 | 990원 | 콜태그 Android |
| `pagero_monthly` | 페이지로 | 3,500원 | 페이지로 웹 |
| `all_monthly` | 통합권 | 6,000원 | 콜태그 Android·페이지로 웹 |

통합권은 전화관리·문자자동화·페이지로를 모두 포함한다.

## 3. 결제 채널

### 3.1 페이지로 웹

페이지로 사용자는 앱 설치 없이 `pagero.kr`에서 가입·체험·결제·해지·결제내역 확인이 가능해야 한다.

페이지로 웹의 주 판매 상품:

- 페이지로 월 3,500원
- 통합권 월 6,000원

페이지로만 이용하는 사용자를 콜태그 앱 설치나 Google Play 결제로 유도하지 않는다.

### 3.2 콜태그 Android

콜태그 Android 앱은 앱 내부 디지털 기능 결제를 Google Play Billing으로 처리한다.

콜태그 앱의 주 판매 상품:

- 전화관리 월 1,900원
- 문자자동화 월 990원
- 통합권 월 6,000원

페이지로 단독 상품은 콜태그의 주 상품으로 강조하지 않는다. 페이지로 연결 화면에서는 현재 페이지로 이용 여부와 통합권 여부만 확인할 수 있게 한다.

### 3.3 통합권

통합권은 어느 채널에서 구매해도 동일한 공통 계정에 귀속된다.

- 페이지로 웹에서 통합권 구매 → 페이지로와 콜태그 모두 활성화
- 콜태그 앱에서 통합권 구매 → 콜태그와 페이지로 모두 활성화
- 동일 `ownerId`로 로그인하면 구매 채널과 관계없이 같은 이용권을 조회

## 4. 통합 이용권 서버

결제 요청은 채널별로 발생하지만 최종 사용 권한은 `inlet-prod`에서 판정한다.

```text
페이지로 웹 PG ─┐
                 ├─ 공통 이용권 서버 ─ 페이지로 권한
Google Play ────┘                    └ 콜태그 권한
```

### 4.1 권장 데이터 모델

#### `billing_subscriptions`

- `id`
- `owner_id`
- `product_code`
- `billing_source`: `web_pg`, `google_play`, `admin`
- `status`: `pending`, `active`, `grace`, `paused`, `canceled`, `expired`, `refunded`, `suspended`
- `external_customer_id`
- `external_subscription_id`
- `purchase_token_hash`
- `started_at`
- `current_period_start`
- `current_period_end`
- `auto_renewing`
- `canceled_at`
- `created_at`
- `updated_at`

#### `account_entitlements`

서비스별 실제 사용 권한을 계산한 결과를 저장하거나 캐시한다.

- `owner_id`
- `call_access_until`
- `message_access_until`
- `pagero_access_until`
- `source_subscription_id`
- `status`
- `updated_at`

#### `trial_grants`

- `owner_id`
- `product_scope`: `call`, `message`, `pagero`, `all`
- `base_days`: 3
- `referral_bonus_days`: 0 또는 5
- `starts_at`
- `ends_at`
- `referral_applied_at`
- `created_at`

기존 `calllink_entitlements`는 베타 무료 활성화를 반복하는 구조이므로, 결제 도입 시 로그인만으로 이용권을 다시 활성화하지 않도록 교체해야 한다.

## 5. 무료 이용 정책

- 기본 무료 이용: 3일
- 추천인 코드 등록: 최초 1회 +5일
- 최대 무료 이용: 8일
- 결제수단을 등록하지 않아도 무료 이용 가능
- 무료기간 종료 후 자동 결제하지 않음
- 사용자가 직접 구독을 시작한 경우에만 결제

### 5.1 서비스별 적용

- 콜태그에서 처음 가입: 선택한 콜태그 상품 또는 통합권 체험
- 페이지로에서 처음 가입: 페이지로 또는 통합권 체험
- 추천 보너스는 계정 전체에서 최초 1회만 지급
- 추천 보너스 지급 후 다른 서비스에서 다시 +5일을 받을 수 없음

### 5.2 악용 방지

- 본인 추천 코드 등록 금지
- 추천인 변경 금지
- 탈퇴 후 재가입을 통한 재지급 금지
- 동일 휴대폰번호·결제계정·기기 기반 반복 혜택 차단
- 첫 유료 결제 이후 추천 코드 등록 제한
- 서버 원자 처리로 중복 지급 방지

## 6. 추천인·파트너 정책

추천인 코드는 콜태그 전용 기능이 아니라 공통 계정 기능이다.

- 콜태그와 페이지로에 동일한 추천인 코드 표시
- 코드 복사·공유 가능
- 추천 링크 지원
- 추천 링크로 가입하면 코드 자동 적용
- 직접 추천 1단계만 수익 인정
- 하위 추천인의 실적에는 수익을 지급하지 않음

### 6.1 파트너 수익

직접 추천한 회원이 유료 구독을 유지하는 동안, 부가세·할인·환불을 제외한 확정 이용료의 20%를 파트너 수익으로 적립한다.

| 상품 | 월 이용료 | 월 파트너 수익 |
|---|---:|---:|
| 전화관리 | 1,900원 | 380원 |
| 문자자동화 | 990원 | 198원 |
| 페이지로 | 3,500원 | 700원 |
| 통합권 | 6,000원 | 1,200원 |

### 6.2 수익 확정 조건

- 무료기간에는 수익 없음
- 실제 결제 승인 후 수익 원장 생성
- 환불·취소·결제취소는 적립 제외 또는 차감
- 결제 채널이 웹 PG인지 Google Play인지와 무관하게 동일 기준 적용
- 추천받은 계정이 정상 구독 상태인 동안 계속 적립
- 부정 가입·자기 추천·중복 계정은 지급 취소

### 6.3 정산 권장안

- 결제 후 60일 지급 대기
- 환불 가능성 확인 후 확정 수익 전환
- 월 1회 정산
- 최소 지급액 50,000원
- 미달 금액은 다음 달 이월
- 출금 전 실명·계좌·세금정보·파트너 약관 동의 필수

정산 화면은 초기에는 별도 네이티브 앱을 만들지 않고 모바일 웹 파트너센터로 제공한다.

## 7. 중복결제 방지

같은 계정에서 서로 다른 채널의 동일 또는 중복 상품을 동시에 결제하지 못하게 한다.

### 7.1 페이지로 웹 결제 중인 경우

콜태그 앱은 다음 정보를 표시하고 중복 구매 버튼을 숨긴다.

- 현재 이용권
- 결제 경로: 페이지로
- 다음 결제일
- 페이지로에서 구독 관리 안내

### 7.2 Google Play 결제 중인 경우

페이지로 웹은 다음 정보를 표시하고 웹 PG 구매 버튼을 숨긴다.

- 현재 이용권
- 결제 경로: Google Play
- 다음 결제일
- Google Play에서 구독 변경·해지 안내

### 7.3 결제 채널 변경

- 기존 구독을 먼저 해지
- 현재 결제기간 종료까지 기존 이용권 유지
- 만료 후 새 결제 채널에서 구독 시작
- 즉시 이중 구독 생성 금지

## 10. 구현 순서

### P0 — 기반

1. 공통 상품 코드와 가격 정본 고정
2. 기존 베타 이용권 자동 활성화 제거
3. 공통 구독·이용권·무료기간·추천 관계 D1 schema
4. 기본 3일·추천 +5일 서버 처리
5. 추천 코드 생성·조회·등록 API
6. 양 서비스에서 동일 추천인 정보 조회

### P1 — 화면

1. 콜태그 더보기의 이용권·결제
2. 콜태그 더보기의 친구 초대·파트너
3. 페이지로 계정의 이용권·결제
4. 페이지로 계정의 친구 초대·파트너
5. 결제 채널과 다음 결제일 표시
6. 이중결제 차단 UI

### P2 — 결제

1. 페이지로 웹 PG
2. 콜태그 Google Play Billing
3. 서버 구매 검증
4. 갱신·취소·환불 동기화
5. 구매 복원
6. 통합권의 양 서비스 권한 반영

### P3 — 파트너 정산

1. 결제 건별 파트너 수익 원장
2. 환불·차감 처리
3. 지급 대기·확정 상태
4. 모바일 웹 파트너센터
5. 본인확인·계좌·세금정보
6. 월간 정산 명세서

## 11. 완료 기준

- 페이지로만 가입한 사용자가 앱 없이 결제 가능
- 콜태그만 가입한 사용자가 Google Play로 결제 가능
- 양쪽에서 구매한 통합권이 동일 계정에 즉시 반영
- 기존 구독이 있을 때 다른 채널 결제 차단
- 기본 3일 체험과 추천 +5일이 정확히 1회 적용
- 콜태그와 페이지로에 같은 추천인 코드 표시
- 결제 채널과 무관하게 추천 수익 20% 생성
- 무료·환불·취소 건에는 수익 미생성 또는 차감
- 로그인만으로 만료된 이용권이 다시 활성화되지 않음
- 모든 결제·추천·정산 변경에 감사 기록 보존

## 13. 최종 원칙

- 페이지로와 콜태그는 별도 서비스다.
- 결제 화면은 각각 제공한다.
- 통합권은 양쪽에서 구매할 수 있다.
- 이용권·추천인·정산 판정은 한 서버에서 처리한다.
- 별도 파트너 앱은 만들지 않는다.
- 복잡한 정산 업무는 모바일 웹 파트너센터로 분리한다.
