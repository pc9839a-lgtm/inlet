1. 설정 메뉴의 주요 항목

현재 설정에는 페이지 기본, 미디어 보관함, 개인 도메인, 계정 정보, 매니저 권한 등의 페이지·계정 관리 메뉴가 있습니다. 고급 메뉴에는 SEO, 추적 코드, 전환 설정, 버전 기록, 페이지 복제, 초기화가 있습니다.

  1. 페이지 기본에서 실제 운영 이름과 주소 정보를 점검합니다.
  2. 미디어 보관함에서는 업로드한 이미지·파일을 관리합니다.
  3. 계정 정보와 매니저 권한에서 접근 가능한 사용자를 확인합니다.
  4. 버전 기록·복제·초기화는 영향 범위를 이해한 뒤 사용합니다.
실무 참고모든 계정에서 모든 메뉴가 보이는 것은 아닙니다. 사용 권한에 따라 표시 항목이 달라질 수 있습니다.

2. 개인 도메인을 연결하기 전

자체 도메인은 기억하기 좋은 주소를 만들 수 있지만 DNS 설정과 인증 단계는 도메인 제공업체의 상태에도 영향을 받습니다.

  1. 도메인 소유 및 관리 권한을 먼저 확인합니다.
  2. 페이지로 설정에서 제공하는 도메인 연결 절차와 안내값을 확인합니다.
  3. DNS 변경 전에 현재 레코드를 보관합니다.
  4. 연결 후 HTTPS 접속과 www 유무, 리디렉션을 실제로 테스트합니다.
실무 참고아직 연결을 완료하지 않았다면 특정 DNS 레코드나 IP 주소를 임의로 넣지 마세요. 화면에 표시되는 안내값이 기준입니다.

3. 권한·복제·초기화의 위험 관리

매니저에게 필요한 권한만 부여하고, 이미 공개된 페이지를 복제할 때는 옛 고객 정보와 링크를 재검증합니다.

  1. 누가 편집·접수 조회·설정을 변경할 수 있는지 확인합니다.
  2. 복제한 페이지의 제목·URL·연락처·픽셀 ID를 새 프로젝트에 맞게 바꿉니다.
  3. 초기화나 복원 전 편집본 백업 여부를 확인합니다.
  4. 수정 후 발행된 페이지와 기존 페이지가 서로 영향을 받지 않는지 테스트합니다.
실무 참고도메인, 권한, 추적 코드 변경은 운영 중인 광고에 영향을 줄 수 있으므로 광고 집행 시점과 분리해 수행하면 위험을 낮출 수 있습니다.

완료 점검

이 문서를 마치기 전에 확인하세요.
  • 설정 메뉴와 계정 권한이 일치하는가
  • 도메인 연결값을 임의로 입력하지 않았는가
  • 복제 후 이전 링크·데이터가 남지 않았는가
  • 중요 변경 전 백업·롤백 수단을 확보했는가

설정 메뉴 일부가 안 보입니다.
