1. 처음에 무엇을 만들지 결정합니다

페이지로는 모바일 페이지를 제작하고 상담·예약을 접수하는 서비스입니다. 시작하기 전에 페이지의 목적을 하나로 좁히면 편집 시간이 줄어듭니다.

  1. 상담 신청, 견적 문의, 방문 예약 중 가장 중요한 행동 하나를 선택합니다.
  2. 방문자가 처음 보게 될 제목과 설명을 1~2문장으로 작성합니다.
  3. 받아야 할 정보는 이름, 연락처, 요청사항 등 업무에 필요한 항목만 추립니다.
실무 참고예를 들어 보험 상담 신청 페이지라면 ‘상담 신청 완료’를 목표로 삼고, 상품 소개와 개인정보 동의·신청 폼을 구성합니다.

2. 로그인 후 첫 페이지를 생성합니다

페이지로 메인에서 로그인한 후 페이지 목록에서 새 랜딩 만들기를 시작합니다. 계정 상태나 요금제에 따라 생성 가능한 페이지 수가 달라질 수 있습니다.

  1. 대시보드의 ‘새 랜딩 만들기’를 선택합니다.
  2. 페이지를 처음부터 만들거나 제공된 템플릿 중 목적에 맞는 항목을 선택합니다.
  3. 제목과 주소에 사용할 값을 지정하고 편집 화면으로 이동합니다.
실무 참고템플릿을 선택했더라도 게시 전에 예시 문구, 이미지, 링크, 연락처가 실제 사업 내용과 일치하는지 확인하세요.

3. 최소 구성을 만든 뒤 실제로 접수합니다

첫 발행에서는 기능을 많이 넣기보다 방문자가 행동할 수 있도록 만드는 것이 중요합니다.

  1. 히어로에 제목과 설명을 작성합니다.
  2. 상담 폼이나 방문 예약 블록을 추가해 필요한 입력 항목을 만듭니다.
  3. 미리보기에서 모바일 레이아웃과 신청 버튼을 확인합니다.
  4. 발행 후 공개 주소에서 테스트로 한 건을 접수하고 접수함에서 확인합니다.
실무 참고미리보기에서 보이는 내용이 공개 페이지에 자동으로 반영되는 것은 아닙니다. 바뀐 내용을 공개하려면 ‘발행’을 실행해야 합니다.

실제 화면 따라하기 · 설정 예제

목표는 화면을 예쁘게 만드는 데서 끝나지 않고, 공개 주소에서 고객 신청 한 건을 정상적으로 접수해 관리자에게 남기는 것입니다. 아래 예제는 실제 사업 정보 대신 가상의 방문 상담 서비스를 사용합니다.

1. 첫 랜딩페이지 1건 완성 예제

필드의 내용은 설명을 위한 예시입니다. 고객 정보, 연락처, 조건은 실제 사업에 맞게 교체하세요.

작업 화면예제 설정값확인할 결과
새 랜딩 만들기페이지 제목: 방문 상담 접수대시보드에서 다른 페이지와 구별 가능
편집 → 히어로제목: 매장 방문 상담을 예약하세요 / 설명: 희망 시간과 문의 사항을 남겨주세요첫 화면에서 방문 목적 이해
편집 → 상담 폼질문: 성함·연락처·문의 내용 / 버튼: 상담 신청방문자가 신청을 완료할 수 있음
편집 → 고정 영역하단 버튼: 상담 신청 / 실제 폼으로 연결모바일 스크롤 중 신청 경로 유지
미리보기 → 발행반응형 화면 확인 후 발행공개 주소에서 최신 편집 내용 표시

2. 첫 발행 후 실측 확인 절차

  1. 시크릿 창에서 실제 공개 페이지를 열고 페이지 제목·이미지·버튼이 정상 표시되는지 확인합니다.
  2. 상담 폼에 업무용 테스트 데이터를 입력하고 정상 제출합니다. 개인 실명·전화번호 대신 적절한 시험값 사용을 권장합니다.
  3. 접수함에서 조회 월과 전체 문의 필터를 확인하고 방금 제출한 건의 접수 시간·질문 답변을 대조합니다.
  4. 외부 연동이 있다면 접수 저장 여부와 알림·전송 성공 여부를 따로 확인합니다.
  5. 검증 완료 후 테스트 접수의 보관·삭제 방침을 정하고 실제 광고 유입을 시작합니다.

완료 점검

이 문서를 마치기 전에 확인하세요.
  • 페이지 제목이 누구에게 무엇을 제공하는지 말해 주는가
  • 신청에 꼭 필요한 항목만 남겼는가
  • 개인정보 동의와 접수 후 화면을 확인했는가
  • 발행 URL에서 테스트 접수가 저장되었는가

자주 묻는 질문

페이지를 만든 직후 공개되나요?

편집과 미리보기만으로 공개되지 않습니다. ‘발행’을 완료하고 실제 공개 주소에서 결과를 확인하세요.

첫 페이지에 모든 블록을 넣어야 하나요?

히어로·서비스 설명·상담 폼처럼 목표 행동에 필요한 블록부터 구성하고 테스트 접수를 확인하세요.
