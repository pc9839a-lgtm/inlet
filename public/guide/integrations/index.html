1. 접수 저장과 외부 전달을 분리합니다

페이지로의 상담 폼은 접수를 기록하는 역할을 하고, 연동 기능은 외부 서비스로 정보를 전달하는 별도 작업입니다. 접수 성공을 외부 전송 성공과 혼동하지 않아야 합니다.

  1. 상담 폼을 발행하고 테스트 신청을 제출합니다.
  2. 접수함에서 실제 레코드를 확인합니다.
  3. 접수함 관리의 ‘외부 연동’과 ‘전송 내역’을 열어 상태를 확인합니다.
  4. 연동 실패라면 먼저 접수 자체가 저장되었는지부터 분류합니다.
실무 참고고객 신청은 저장되었는데 외부 알림만 실패했다면 고객에게 재제출을 요구하기 전에 연동 상태를 조사하는 편이 안전합니다.

2. 외부 사이트에 폼을 넣는 경우

상담 폼 편집에는 ‘외부 사이트에 넣기’ 기능이 있습니다. 외부 삽입은 기존 사이트에 페이지로 폼을 사용할 때 도움이 되지만, 삽입 환경에 따라 제약이 생길 수 있습니다.

  1. 상담 폼에서 외부 사이트에 넣기 옵션을 확인합니다.
  2. 제공된 삽입 방법을 사용하는 사이트의 편집 환경에 맞게 적용합니다.
  3. 모바일에서 폼이 잘리지 않는지 검증합니다.
  4. 테스트로 신청한 뒤 페이지로 접수함에서 저장 여부를 확인합니다.
실무 참고외부 사이트에 삽입된 폼도 개인정보 안내와 접수 처리 책임을 별도로 검토해야 합니다.

3. 운영 중 흔한 오류

전송 실패와 접수 실패, 중복 차단은 각각 원인이 다를 수 있습니다.

  1. 전송 내역에서 실패 건의 시간과 상태를 확인합니다.
  2. 폼의 중복 접수 기준 때문에 재신청이 막힌 것은 아닌지 확인합니다.
  3. 연동 대상 서비스의 인증·권한·연결 상태가 유지되는지 점검합니다.
  4. 재시도 전에 중복 저장 또는 중복 알림이 생기지 않는지 주의합니다.
실무 참고자동으로 지원되는 외부 서비스 종류와 연동 방식은 현재 계정의 실제 설정 화면을 기준으로 확인하세요. 제공되지 않는 자동화를 이 문서만 보고 구현되었다고 가정하면 안 됩니다.

완료 점검

이 문서를 마치기 전에 확인하세요.
  • 접수함에 정상 레코드가 생성되었는가
  • 외부 전송 성공 여부를 별도 확인했는가
  • 삽입 폼이 모바일에서 정상 동작하는가
  • 재시도로 중복 알림·접수가 발생하지 않는가

자주 묻는 질문

접수는 있는데 알림이 안 와요.

접수 저장과 외부 전달은 별개입니다. 접수함의 ‘전송 내역’에서 실패 여부를 확인하세요.

외부 사이트에 폼을 넣으면 접수가 저장되나요?

삽입 후 외부 사이트에서 시험 제출하고 페이지로 접수함에 실제 기록이 남는지 확인하세요.
