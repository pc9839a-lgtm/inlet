1. 편집 화면의 세 영역

현재 편집기는 페이지에 들어갈 항목을 고르는 ‘구성’, 선택한 항목의 값을 바꾸는 ‘선택 항목 편집’, 실제 결과를 보여 주는 미리보기로 이루어집니다. 별도의 ‘스타일’ 탭을 찾기보다 편집 안의 페이지 설정을 이용하세요.

  1. 구성 목록에서 수정하려는 블록을 선택합니다.
  2. 오른쪽 편집 영역에서 해당 블록의 제목·내용·옵션을 수정합니다.
  3. 미리보기에 반영된 모습을 확인하고 필요한 경우 다른 블록으로 이동합니다.
실무 참고미리보기에서 특정 블록을 눌러 해당 편집 항목을 찾아갈 수 있는 상황도 있습니다. 선택한 블록 이름을 먼저 확인하면 잘못된 영역을 수정하는 일을 줄일 수 있습니다.

2. 블록을 추가하고 순서를 바꿉니다

히어로, 이미지, 텍스트, 카드, 지도, 상담 폼, 방문 예약 등 블록을 조합해 페이지를 제작합니다.

  1. ‘블록 추가’를 열어 목적에 맞는 블록을 고릅니다.
  2. 새 블록의 기본 내용을 실제 내용으로 교체합니다.
  3. 구성 목록에서 순서를 조절해 방문자가 읽을 순서를 맞춥니다.
  4. 불필요한 블록은 삭제하기 전 중복·복제 여부와 실제 연결을 확인합니다.
실무 참고보통 첫 화면에는 히어로, 중간에는 설명·증거, 마지막에는 상담 폼을 둡니다. 블록은 많을수록 좋은 것이 아니라 전환에 필요한 만큼만 남기는 편이 좋습니다.

3. 고정 영역과 페이지 설정

‘상단 메뉴’, ‘하단 고정 버튼’, ‘푸터’는 일반 콘텐츠와 구분되는 고정 영역입니다. 페이지 전체 색상·글꼴·배경은 ‘페이지 설정’에서 변경합니다.

  1. 상단 메뉴에서 필요한 이동 항목을 편집합니다.
  2. 하단 고정 버튼에서 실제 행동 문구와 연결 대상을 확인합니다.
  3. 푸터에서 사업자·연락처·법적 문서 등 필요한 내용을 점검합니다.
  4. 페이지 설정을 열어 색상과 글꼴, 배경과 정렬을 조절합니다.
실무 참고버튼을 추가만 하면 동작이 완성되는 것은 아닙니다. 각 버튼이 연결할 URL·전화·폼 위치를 실제 방문 화면에서 시험해야 합니다.

실제 화면 따라하기 · 설정 예제

현재 페이지로 편집은 고정된 메뉴 여러 개를 왕복하는 방식보다, 왼쪽 구성에서 수정 대상을 고르고 선택 항목 편집에서 해당 값을 변경하는 방식입니다. ‘페이지 설정’은 전체 색상·배경을 조절하는 별도 영역입니다.

1. 편집기 세 영역별 역할

화면 위치여기서 하는 일주의할 점
구성블록 추가, 순서 변경, 고정 영역 선택이곳에서 선택한 블록이 실제 편집 대상입니다.
선택 항목 편집히어로 문구·폼 질문·이미지 등 개별 값 수정아무 블록도 선택하지 않았다면 ‘블록을 선택하세요’가 보일 수 있습니다.
페이지 설정포인트 색상, 글꼴, 배경, 전체 정렬블록마다 설정하는 글자 디자인과 페이지 전체 설정은 다릅니다.
미리보기PC·모바일 배치 및 버튼 결과 확인미리보기만으로 외부 공개가 완료되지 않습니다.

2. 상담 페이지에 필요한 블록만 배치하기

  1. 기존 페이지를 열고 ‘구성’의 블록 추가에서 히어로를 선택합니다. 제목·설명에 상담 목적을 작성합니다.
  2. 텍스트 또는 카드를 추가해 상담 대상, 준비 자료, 안내 범위를 작성합니다.
  3. 상담 폼을 추가하고 이름·연락처·요청사항 등 꼭 필요한 항목을 설정합니다.
  4. 고정 영역에서 하단 고정 버튼이 상담 폼과 연결되는지 검증합니다.
  5. 블록 순서를 히어로 → 서비스 안내 → 신뢰 요소 → 상담 폼 순으로 확인하고 실제 서비스에 불필요한 섹션을 제거합니다.

3. 블록 작업 중 자주 하는 실수

실수결과수정 방법
가까운 블록을 잘못 선택변경사항이 다른 카드·본문에 반영구성에서 현재 선택된 블록 제목 확인
이미지에 중요한 가격 문구만 기입이미지 확대·축소시 안내 문구가 읽히지 않음HTML 텍스트에도 필수 정보를 기재
상단·하단 고정 영역을 일반 블록과 혼동버튼이나 메뉴가 의도와 다르게 동작구성의 ‘고정 영역’을 직접 선택
편집 후 발행을 누르지 않음방문자에게 변경사항이 보이지 않음미리보기 점검 후 ‘발행’ 실행

완료 점검

이 문서를 마치기 전에 확인하세요.
  • 선택한 블록과 편집 영역이 일치하는가
  • 블록 순서가 방문자의 읽기 순서에 맞는가
  • 고정 버튼이 콘텐츠를 가리지 않는가
  • 삭제·복제 후 미리보기에 이상이 없는가
