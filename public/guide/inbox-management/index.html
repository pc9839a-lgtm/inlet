1. 접수함에서 문의를 선별합니다

현재 접수함에는 전체 문의, 신규, 처리중, 완료, 스팸·중복 등이 있으며 접수 목록을 검색할 수 있습니다.

  1. 상단 메뉴에서 ‘접수함’을 엽니다.
  2. 전체 문의와 신규 항목을 먼저 확인합니다.
  3. 이름·연락처·문의 검색과 조회 월, 유형, 상태 필터를 사용합니다.
  4. 행을 선택해 입력 답변과 접수 시간, 유입 정보를 확인합니다.
실무 참고이름이나 전화번호를 다른 사람에게 전달하기 전에는 업무상 필요한 범위인지 검토합니다. 접수 상세에는 개인정보가 포함됩니다.

2. 상태와 메모로 후속 업무를 관리합니다

접수의 상태는 단순히 색을 바꾸는 기능이 아니라 누가 어떤 후속 행동을 해야 하는지 나타내는 표시입니다.

  1. 처음 접수된 문의는 ‘신규’에서 확인합니다.
  2. 실제 통화·견적·확인 작업을 진행하면 처리중 상태로 관리합니다.
  3. 작업 완료 후 완료로 변경합니다.
  4. 내부 메모에는 고객에게 다시 확인할 사항과 다음 행동을 짧게 남깁니다.
실무 참고예를 들어 ‘10/29 통화 완료, 시공 가능일 확인 후 회신’처럼 다음 담당자가 보고 바로 이해할 수 있게 기록합니다.

3. 중복·외부 연동·다운로드

접수함 관리 메뉴에는 중복 정책, 외부 연동, 전송 내역이 있습니다. CSV 내보내기 역시 개인정보 취급에 주의해야 합니다.

  1. 스팸·중복 분류를 확인하고 정상 고객이 잘못 분류되지 않았는지 검사합니다.
  2. 외부 연동으로 전달되지 않은 건은 ‘전송 내역’에서 상태를 구분해 살핍니다.
  3. CSV를 다운로드할 때는 화면의 개인정보 확인 절차를 읽고 진행합니다.
  4. 필요가 끝난 다운로드 파일은 회사의 보관·삭제 정책에 따라 관리합니다.
실무 참고폼 접수가 저장된 것과 외부 알림이 성공한 것은 다른 사건입니다. 전송 실패라고 접수 자체가 없는 것으로 판단하지 마세요.

2. 하루 접수 처리 예제

  1. ‘전체 문의’에서 조회 월을 오늘이 속한 달로 맞추고 새로고침합니다.
  2. ‘신규’에서 연락처와 고객이 남긴 답변을 확인합니다.
  3. 고객에게 연락 중이면 상태를 ‘확인중’으로 바꿉니다.
  4. 접수 메모에 ‘확인한 내용 / 요청 자료 / 다음 행동 / 예정 시점’을 적습니다.
  5. 상담이 끝나면 상황에 따라 ‘연락완료’, ‘예약완료’, ‘보류’, ‘종료’로 변경합니다.
  6. 외부 알림이 안 온 고객은 접수 자체가 남아 있는지 확인한 뒤 ‘전송 내역’으로 이동합니다.

접수함 6건을 상태별로 분류하는 실무 예제

접수함의 ‘신규·처리중·완료’는 단순한 화면 장식이 아니라 접수 상태를 묶어 보여주는 그룹입니다. 현재 코드에서 처리중에는 확인중·보류, 완료에는 연락완료·예약완료·종료가 포함됩니다. 스팸·중복 위험표시는 상태 그룹과 구분해 확인합니다.

예약완료도 완료 그룹에 속합니다. 반대로 보류는 미완료이므로 일정이 지나지 않았는지 확인해야 합니다. 이 표는 작업 흐름을 보이는 가상 상태이며 통계에서 실제 이용자의 접수 상태를 재현한 결과는 아닙니다.

상담 완료 메시지는 떴는데 접수함에 없어요

  1. 현재 페이지 확인: 테스트한 공개 URL과 접수함이 연결된 페이지가 같은지 확인합니다.
  2. 조회 월 확인: 월별 필터가 과거 달로 설정되어 있으면 새 기록이 화면에 보이지 않습니다.
  3. 필터 초기화: 상담·예약 유형, 상태, 이름·연락처 검색어를 모두 초기화하고 ‘전체 문의’를 확인합니다.
  4. 중복 위험표시 확인: 스팸·중복 신호가 있는 기록도 자동으로 모두 삭제됐다고 가정하지 말고 분류와 실제 저장 여부를 나눠 확인합니다.
  5. 전송 내역 확인: 접수가 있는데 이메일·외부 연동 알림만 오지 않는다면 ‘알림 실패’ 또는 ‘일부 실패’ 항목을 확인합니다.
  6. 문제가 지속되면: URL, 발생 시각, 오류 문구만 기록해 재현하고 실제 고객의 전화번호 등 개인정보를 공개 화면에 붙여 넣지 않습니다.

접수 저장과 외부 알림은 다른 상태입니다

접수함 기록외부 알림해석·후속 조치

CSV 내보내기에는 문의 내용·이름·연락처 등 개인정보가 들어갈 수 있습니다. 업무 승인된 장치에서 내려받고, 필요한 자료만 남기며 보관·삭제 기간과 전달 대상을 점검하세요.
