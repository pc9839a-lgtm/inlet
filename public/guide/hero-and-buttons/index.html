1. 히어로에 한 가지 목적을 담습니다

히어로는 방문자가 화면을 열었을 때 처음 보는 핵심 콘텐츠입니다. 편집기의 히어로에서 ‘제목’과 ‘설명’을 수정할 수 있습니다.

  1. 제목에는 상품·서비스와 방문자의 이득을 직접 작성합니다.
  2. 설명은 대상·범위·조건 가운데 빠뜨리면 안 되는 정보를 짧게 적습니다.
  3. 문장을 읽는 데 오래 걸린다면 먼저 핵심만 남기고 상세 설명을 아래 블록으로 옮깁니다.
실무 참고예시: ‘인테리어 견적, 현장 상황부터 확인합니다.’ / ‘공간 사진과 희망 일정을 남겨주시면 상담 가능 여부를 확인합니다.’

2. 히어로 이미지가 텍스트를 가리지 않게 합니다

히어로 이미지 설정에는 글 위, 글 뒤, 전체 이미지처럼 배치 방식이 있으며 이미지 높이·필터 진하기·글자 표시를 조절할 수 있습니다.

  1. 실제 서비스와 관련된 사진을 업로드합니다.
  2. 글 뒤에 이미지를 배치하면 제목의 명도 대비가 유지되는지 확인합니다.
  3. 모바일 폭에서 인물이나 핵심 피사체가 잘리는지 점검합니다.
  4. 의미 없는 장식보다 서비스 이용 장면이나 결과물 이미지를 우선합니다.
실무 참고이미지에 가격이나 필수 안내 문구를 직접 넣으면 작은 화면에서 읽기 어렵습니다. 중요한 텍스트는 HTML 제목과 설명에도 포함하세요.

3. 하단 고정 버튼 연결

하단 고정 버튼은 긴 모바일 페이지에서 방문자가 언제든 행동할 수 있게 하는 영역입니다. 편집 화면의 ‘고정 영역’에서 버튼과 타이머·디자인 옵션을 확인할 수 있습니다.

  1. 버튼 문구는 ‘상담 신청’, ‘방문 예약’처럼 클릭 후 행동을 나타내게 씁니다.
  2. 연결 유형에 맞춰 폼·예약·전화·링크 대상으로 연결합니다.
  3. 미리보기와 공개 페이지에서 실제 클릭이 목적지로 이동하는지 확인합니다.
실무 참고버튼 문구만 바뀌고 연결 대상은 이전 캠페인으로 남는 경우가 있습니다. 다른 페이지를 복제했을 때 특히 중요합니다.

완료 점검
