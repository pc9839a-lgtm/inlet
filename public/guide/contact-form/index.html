1. 상담 폼 기본 정보를 입력합니다

편집에서 ‘상담 폼’ 블록을 선택하면 제목·설명·입력 항목·버튼 문구를 수정할 수 있습니다.

  1. 폼 제목에는 ‘견적 문의’, ‘상담 신청’처럼 행동을 명확히 적습니다.
  2. 설명에는 회신 방식이나 필요한 사전 정보를 적습니다.
  3. 입력 항목 목록에서 질문을 추가하고 제목·선택지·필수 여부를 점검합니다.
  4. 신청 버튼 문구를 실제 행동과 일치하도록 변경합니다.
실무 참고예시 구성: 성함(필수), 연락처(필수), 희망 서비스(선택형), 요청 내용(장문). 필요한 정보만 수집할수록 입력 중 이탈을 줄일 여지가 있습니다.

2. 개인정보 동의와 접수 후 화면

‘개인정보’와 ‘접수 후 화면’은 상담 폼 안에서 펼쳐 수정할 수 있습니다. 개인정보 수집·이용 안내는 실제 운영 목적과 수집 항목에 맞춰 작성해야 합니다.

  1. 개인정보 동의의 필수 여부를 업무와 법적 요건에 맞게 검토합니다.
  2. 안내문에는 수집 목적·항목·보유기간 등 필요한 내용을 운영 정책과 일치시키도록 검토합니다.
  3. 접수 후 화면에서 완료 제목과 설명을 수정합니다.
  4. 확인 메시지에 ‘접수가 완료되었습니다’와 다음 연락 예상 절차를 적습니다.
실무 참고페이지로가 제공하는 입력 UI와 별개로 실제 수집·이용 정책의 적합성은 운영자가 확인해야 합니다. 예시 문구를 그대로 쓰지 마세요.

3. 중복 접수 정책과 테스트

폼 편집의 ‘중복 접수’에는 연락처·이메일 기준 정책과 기간 설정이 있습니다. 연락처는 허용·알림·차단, 이메일은 사용 안 함·알림·차단 등의 선택지가 제공됩니다.

  1. 연락처를 반복 입력할 수 있어야 하는 행사인지 먼저 결정합니다.
  2. 중복 기준 기간(1일·3일·7일·30일 등)을 실제 운영 방식에 맞춥니다.
  3. 발행 후 스마트폰에서 정상 접수 한 건을 제출합니다.
  4. 접수함에서 질문 답변·접수 시각·상태를 확인하고, 중복 시나리오도 별도로 시험합니다.
실무 참고화면에 성공 메시지가 보인 것과 관리자가 정상 접수를 확인한 것은 서로 다른 검증입니다. 접수함의 실제 기록을 반드시 확인하세요.

3. 편집기에서 항목을 정확히 만드는 순서

  1. 상담 폼 블록을 선택하고 ‘제목’과 ‘설명’을 입력합니다.
  2. ‘입력 항목’에서 ‘항목 추가’를 열어 이름, 연락처, 선택형 등 질문 유형을 고릅니다.
  3. 생성된 질문을 눌러 라벨·유형·필수 여부·입력 안내 문구를 설정합니다. 선택/복수 선택은 선택지도 설정합니다.
  4. 질문 카드를 드래그하거나 이동 기능을 사용해 모바일에서 작성하기 편한 순서로 바꿉니다.
  5. ‘개인정보’ 영역에서 수집 목적·항목·보유기간 등 실제 운영 기준을 검토하고, ‘접수 후 화면’의 제목·문구를 작성합니다.
  6. ‘중복 접수’에서 연락처(허용/알림/차단), 이메일(사용 안 함/알림/차단), 기간(1·3·7·30일)을 업무에 맞게 정합니다.

자주 묻는 질문

선택과 복수 선택은 어떻게 다른가요?

선택은 하나의 답변, 복수 선택은 여러 답변을 받습니다. 각각 선택지와 필수 여부를 설정하세요.

같은 연락처의 신청이 차단됩니다.
