1. 통계 메뉴의 네 가지 화면

페이지로 통계에는 ‘개요’, ‘전환’, ‘유입’, ‘접수’ 화면이 있습니다. 조회 기간과 유입 채널 필터를 함께 보면 동일한 방문도 다른 관점에서 확인할 수 있습니다.

  1. ‘통계’를 열고 먼저 개요를 확인합니다.
  2. 필요한 기간을 선택하고 직전 동일 기간 대비 변화가 표시되는지 봅니다.
  3. 전환 화면에서 폼 시작과 제출 시도를 확인합니다.
  4. 유입 화면에서 검색·광고·직접 방문 등의 채널을 비교합니다.
실무 참고조회 기간이 다르면 숫자를 단순 비교하면 안 됩니다. 광고 관리자와 페이지로의 보고 시점·집계 범위를 맞춰야 합니다.

2. 지표별 의미를 구분합니다

PV는 페이지 조회, CTA는 버튼 클릭, 접수는 실제 제출 성공 데이터와 관련된 지표입니다. 폼 시작·제출 시도·제출 성공은 서로 다른 단계입니다.

  1. 페이지 조회 대비 폼 시작 수를 비교해 첫 화면의 관심을 살핍니다.
  2. 폼 시작 대비 제출 성공이 낮다면 입력 문항·에러·동의 과정을 확인합니다.
  3. 제출 성공과 접수함 기록을 대조합니다.
  4. 예약과 상담 접수가 섞여 있다면 유형별로 따로 비교합니다.
실무 참고예: 조회 500회, 폼 시작 80회, 제출 성공 20회라면 조회 대비 성공 비율은 4%입니다. 이 값은 실제 구매·계약 전환율과 같지 않습니다.

3. 숫자가 맞지 않을 때

Meta 또는 Google 광고 관리자의 ‘전환’은 픽셀 이벤트 기준이고, 페이지로 접수함은 저장된 신청 데이터 기준일 수 있습니다.

  1. 비교 대상의 날짜와 시간대를 통일합니다.
  2. 테스트 신청, 중복 이벤트, 완료 화면 재방문이 포함됐는지 확인합니다.
  3. 접수함의 실제 신청 건수를 따로 확보합니다.
  4. 차이가 유지되면 추적 코드와 전환 설정을 확인합니다.
실무 참고광고 관리자가 30건, 접수함이 18건이라고 해서 시스템 장애라고 단정할 수 없습니다. 먼저 각 지표가 무엇을 세는지 확인해야 합니다.
