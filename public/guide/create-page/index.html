1. 대시보드에서 페이지 생성

페이지로 로그인 후 페이지 목록은 제작 중인 페이지를 관리하는 시작점입니다. ‘새 랜딩 만들기’는 계정의 생성 가능 여부에 따라 비활성화될 수 있습니다.

  1. 페이지 목록에서 새 랜딩 만들기를 선택합니다.
  2. 직접 제작 또는 템플릿 등 사용 가능한 제작 방식을 선택합니다.
  3. 페이지 주제와 맞는 시작안을 고른 뒤 편집 화면을 엽니다.
실무 참고새 랜딩 만들기가 비활성화되어 있다면 같은 버튼을 반복하지 말고 계정의 페이지 사용 현황과 요금제 제한을 먼저 확인합니다.

2. 제목과 주소를 구분합니다

페이지 제목은 편집기와 사용자에게 보이는 이름이고, 페이지 주소는 외부에 전달하는 접속 경로입니다. 고객에게 공유할 주소는 짧고 혼동되지 않게 선택합니다.

  1. 내부에서 구별하기 쉬운 페이지 제목을 작성합니다.
  2. 주소에는 띄어쓰기·특수기호를 피하고 간단한 영문과 숫자 조합을 사용합니다.
  3. 주소 중복 검사나 저장 오류가 나면 다른 이름으로 변경합니다.
실무 참고예를 들어 ‘10월 무료상담’처럼 매월 달라지는 행사명보다는 브랜드·서비스 중심 주소가 장기간 운영하기 편합니다.

3. 공개 전 꼭 확인할 항목

주소는 인쇄물·광고 소재에 들어간 뒤 바꾸기 어려울 수 있습니다.

  1. 이름, 상담 유형, 운영 연락처가 다른 페이지와 섞이지 않았는지 확인합니다.
  2. 제공된 샘플 문구·이미지가 남지 않았는지 검사합니다.
  3. 공개 주소를 브라우저에서 열어 실제로 접속되는지 확인합니다.
실무 참고페이지가 아직 발행되지 않았다면 주소를 입력해도 완성된 콘텐츠가 보이지 않을 수 있습니다. 편집 완료와 발행 완료를 구별하세요.

페이지 주소가 저장되지 않을 때까지 확인하는 생성 예제

새 랜딩은 직접 제작·템플릿 기반 제작·AI 초안 중 계정에서 제공되는 방식으로 시작할 수 있습니다. 현재 코드에서는 직접 제작과 템플릿 제작 모두 새 페이지를 만든 후 서버 저장을 시도합니다. AI 초안의 생성 기능은 계정 권한과 연결 상태에 따라 이용 가능 여부가 달라지며, AI 연결이 실패하면 입력 내용을 바탕으로 한 기본 구조로 시작할 수 있습니다.

공개 주소 입력값의 실제 판정 기준

주소는 소문자 영문과 숫자, 하이픈을 중심으로 짧게 작성하는 것이 좋습니다. 생성 코드가 확인하는 최소 길이는 3자, 최대 길이는 48자입니다. 예약어·문자 형식·중복 사용 여부도 확인합니다.

생성 후 공개까지 실제 검증

  1. 페이지 목록에서 새 랜딩 만들기를 선택하고 현재 계정에서 제공되는 제작 방식을 고릅니다.
  2. 페이지 이름과 외부 공유 주소를 구분해 입력합니다. 주소 오류가 있다면 문구에 따라 수정하고, 중복 경고를 무시하지 않습니다.
  3. 저장 실패 안내가 표시되면 브라우저의 임시 데이터만 남아 있을 수 있습니다. 새 페이지가 공개 서버에 저장됐다고 간주하지 않습니다.
  4. 템플릿이나 AI 초안을 사용했다면 운영자 정보·샘플 문구·버튼 연결·추적 코드를 실제 값으로 변경합니다.
  5. 미리보기로 모바일 화면을 확인한 뒤 명시적으로 발행하고 공개 URL에서 제목과 폼 동작을 검증합니다.
  6. 동의한 테스트 담당자의 정보로 1건을 제출했다면 완료 화면과 접수함에 동일한 신청 기록이 남는지 대조합니다.

이 가이드는 실제 고객 전환율을 제시하거나 특정 제작 방식이 더 높은 성과를 낸다고 주장하지 않습니다. 계정별 페이지 수 제한이 발생하면 무리하게 기존 페이지를 삭제하기 전에 요금제와 공개 페이지 현황을 확인하세요.
