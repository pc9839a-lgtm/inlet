1. 대시보드에서 페이지 생성

페이지로 로그인 후 페이지 목록은 제작 중인 페이지를 관리하는 시작점입니다. ‘새 랜딩 만들기’는 계정의 생성 가능 여부에 따라 비활성화될 수 있습니다.

  1. 페이지 목록에서 새 랜딩 만들기를 선택합니다.
  2. 직접 제작 또는 템플릿 등 사용 가능한 제작 방식을 선택합니다.
  3. 페이지 주제와 맞는 시작안을 고른 뒤 편집 화면을 엽니다.
실무 참고새 랜딩 만들기가 비활성화되어 있다면 같은 버튼을 반복하지 말고 계정의 페이지 사용 현황과 요금제 제한을 먼저 확인합니다.

2. 제목과 주소를 구분합니다

페이지 제목은 편집기와 사용자에게 보이는 이름이고, 페이지 주소는 외부에 전달하는 접속 경로입니다. 고객에게 공유할 주소는 짧고 혼동되지 않게 선택합니다.

  1. 내부에서 구별하기 쉬운 페이지 제목을 작성합니다.
  2. 주소에는 띄어쓰기·특수기호를 피하고 간단한 영문과 숫자 조합을 사용합니다.
  3. 주소 중복 검사나 저장 오류가 나면 다른 이름으로 변경합니다.
실무 참고예를 들어 ‘10월 무료상담’처럼 매월 달라지는 행사명보다는 브랜드·서비스 중심 주소가 장기간 운영하기 편합니다.

3. 공개 전 꼭 확인할 항목

주소는 인쇄물·광고 소재에 들어간 뒤 바꾸기 어려울 수 있습니다.

  1. 이름, 상담 유형, 운영 연락처가 다른 페이지와 섞이지 않았는지 확인합니다.
  2. 제공된 샘플 문구·이미지가 남지 않았는지 검사합니다.
  3. 공개 주소를 브라우저에서 열어 실제로 접속되는지 확인합니다.
실무 참고페이지가 아직 발행되지 않았다면 주소를 입력해도 완성된 콘텐츠가 보이지 않을 수 있습니다. 편집 완료와 발행 완료를 구별하세요.
