1. 블록은 정보의 역할에 맞춰 고릅니다

이미지는 제품·현장의 모습을 보여 주고, 텍스트는 조건을 설명하며, 카드는 여러 항목을 비교하는 데 유용합니다. 지도는 방문 위치 확인, FAQ는 반복 질문 처리에 활용합니다.

  1. 설명이 길다면 텍스트 블록으로 나누고 제목을 붙입니다.
  2. 서로 비슷한 혜택·서비스는 카드로 묶어 비교합니다.
  3. 오프라인 매장이면 지도와 주소를 함께 제시합니다.
  4. 자료 제공이 필요할 때는 다운로드 블록의 파일과 링크를 확인합니다.
실무 참고예를 들어 상담 신청 페이지에서는 히어로 → 대표 이미지 → 제공 서비스 카드 → FAQ → 상담 폼 순서가 자연스럽습니다.

2. 유형별 유의사항

페이지로는 이미지·동영상·텍스트·카드·링크·자료 다운로드·지도·일정·FAQ·타이머·구분선 등 여러 블록을 제공합니다. 모든 블록을 한 페이지에 넣을 필요는 없습니다.

  1. 이미지는 모바일 화면에서 중요한 피사체가 보이는지 확인합니다.
  2. 동영상은 재생 가능 여부와 페이지 속도에 미치는 영향을 확인합니다.
  3. 지도는 주소 및 실제 위치가 일치하는지 확인합니다.
  4. FAQ에는 상담자가 반복해서 받는 질문만 우선 추가합니다.
실무 참고상세 설명이 필요한 기능도 실제 입력 화면과 공개 미리보기 결과를 함께 살피는 것이 정확합니다. 블록별 옵션은 업데이트에 따라 바뀔 수 있습니다.

3. 짧은 모바일 페이지로 다듬습니다

콘텐츠가 많아질수록 방문자가 원하는 행동을 찾지 못할 수 있습니다.

  1. 비슷한 내용의 카드와 설명을 합칩니다.
  2. 첫 화면에서 가장 중요한 혜택과 신청 방법을 드러냅니다.
  3. 버튼과 폼 사이에 불필요한 장식 요소가 없는지 확인합니다.
  4. 모바일 360·390·430px 폭에서 가로 스크롤과 잘림을 검증합니다.
실무 참고긴 문구를 무조건 줄이기보다 가격·제한조건·동의사항처럼 판단에 필요한 정보가 빠지지 않도록 균형을 맞춥니다.

완료 점검

이 문서를 마치기 전에 확인하세요.
  • 각 블록에 필요한 정보만 남았는가
  • 이미지와 지도에 사실과 다른 정보가 없는가
  • 모바일에서 가로 스크롤이 발생하지 않는가
  • FAQ가 실제 고객 질문에 답하는가

자주 묻는 질문

카드와 텍스트 중 무엇을 사용해야 하나요?

여러 항목을 비교하려면 카드, 연속된 상세 설명에는 텍스트가 적합합니다.

모바일에서 이미지가 잘려요.

이미지 배치와 크기를 확인하세요. 원본 가장자리에 중요한 내용이 있으면 이미지 교체도 고려해야 합니다.
