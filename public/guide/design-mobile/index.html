1. 디자인은 편집 안의 페이지 설정에서

현재 편집기의 별도 스타일 탭 대신 ‘편집 → 페이지 설정’에서 페이지 전체 디자인을 수정합니다. 글꼴, 주요 색상, 배경과 정렬은 이 영역의 옵션입니다.

  1. 편집 화면의 구성 영역에서 ‘페이지 설정’을 엽니다.
  2. 버튼 색상과 본문 글자 색상을 선택합니다.
  3. Pretendard 등 제공되는 글꼴 가운데 한 가지를 고릅니다.
  4. 배경 방식과 정렬을 선택한 다음 미리보기 결과를 확인합니다.
실무 참고새 스타일을 편집본에 적용한 뒤에도 공개 페이지에는 발행이 필요할 수 있습니다. 화면의 미적용·발행 상태 표시를 확인하세요.

2. 배경은 글 읽기에 방해되지 않게

페이지 설정에는 단색·그라데이션·이미지 배경과 관련된 옵션이 있습니다. 이미지 배경에는 맞춤 방식·위치·필터 같은 조절 항목이 제공될 수 있습니다.

  1. 배경색과 본문색의 대비를 먼저 확인합니다.
  2. 이미지를 사용할 경우 제목과 버튼이 배경에 묻히지 않도록 필터를 조절합니다.
  3. 블록마다 별도 강조 색상을 늘리기보다 한 가지 주요 색상을 중심으로 유지합니다.
  4. 장식 효과는 실제 정보 전달을 방해하지 않는 범위에서 사용합니다.
실무 참고예를 들어 신청 버튼을 진한 색상으로 표시한다면 보조 버튼·설명 글자까지 같은 강도로 강조하지 않는 편이 행동을 구별하기 쉽습니다.

3. 모바일 검증 체크

페이지로 제작물은 모바일 랜딩에 사용되는 경우가 많습니다. 데스크톱 미리보기만으로는 충분하지 않습니다.

  1. 360px·390px·430px 정도의 좁은 폭에서 순서대로 확인합니다.
  2. 텍스트가 화면 밖으로 밀리거나 좌우 스크롤이 생기는지 검사합니다.
  3. 하단 고정 버튼이 상담 폼 마지막 입력 칸이나 제출 버튼을 가리지 않는지 확인합니다.
  4. 긴 질문과 선택지를 실제 스마트폰에서 터치해 봅니다.
실무 참고이미지의 품질은 원본 파일과 배치 방식의 영향을 받습니다. 확대·축소로 해결되지 않으면 원본 이미지의 구성 자체를 조정하세요.

완료 점검

이 문서를 마치기 전에 확인하세요.
  • 색상 대비와 텍스트 가독성이 충분한가
  • 페이지 설정을 편집본에 적용했는가
  • 360/390/430px에서 잘림과 가로 스크롤이 없는가
  • 고정 버튼과 폼 제출 버튼이 겹치지 않는가
