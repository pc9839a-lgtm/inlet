사용방법

설정은 한 번,
발송은 자동으로.

복잡한 자동화 도구를 연결하지 않아도 됩니다. 안내문자를 작성하고 기능을 켜두면 통화 뒤 반복 업무가 줄어듭니다.

01

안내문자를 작성합니다

통화 완료, 부재중, 발신 통화 상황에 맞춰 보낼 문구를 각각 설정합니다.

02

평소처럼 통화합니다

삼성전화, T전화 등 기존에 사용하던 전화 앱을 그대로 이용합니다.

03

문자가 자동으로 갑니다

통화가 끝나면 설정한 안내문자가 고객에게 발송되고 기록이 남습니다.

주요기능

전화 뒤에 필요한 일만 남겼습니다.

기능을 복잡하게 늘리기보다 실제 상담 현장에서 반복되는 문자 작성과 고객 확인을 빠르게 처리하도록 구성했습니다.

↗

상황별 자동문자

통화 완료, 부재중·거절, 발신 통화에 서로 다른 안내문자를 설정할 수 있습니다.

→

◷

⌁

중복발송과 시간 제한

→

권한과 개인정보

필요한 기능만 사용하고, 통화내용은 다루지 않습니다.

콜링크는 통화 종료를 확인하고 설정한 문자를 보내기 위해 필요한 Android 권한을 사용합니다. 자동문자는 사용 중인 휴대폰의 기본 문자 회선으로 발송됩니다.

1
통화내용을 녹음하지 않습니다통화 상태와 발송에 필요한 최근 기록만 확인합니다.
2
주소록 전체를 임의 업로드하지 않습니다고객을 추가할 때 사용자가 선택한 연락처만 이용합니다.
3
권한은 언제든 해제할 수 있습니다Android 앱 설정에서 전화·통화기록·문자 권한을 직접 관리합니다.
